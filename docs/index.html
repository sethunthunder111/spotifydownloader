Paste a Spotify link, get tagged MP3s.

spotify-dl looks up each track on Spotify, finds the album recording on YouTube Music, and saves an MP3 with title, artist, album, year and cover art to your Music folder.

Download for Windows View source on GitHub

Free and open source under the MIT license. Windows 10 and 11, 64-bit.

What it does

Matching on YouTube Music, parallel downloads, one folder per album, real ID3 tags, and a menu you can drive from the keyboard.

Songs, albums and playlists
Paste a link, a spotify: URI or a bare ID. Albums and playlists get their own subfolder with a cover.jpg, and the log shows each track. Playlists work for ones you own or collaborate on.
Search by name
Type “Artist - Title” and spotify-dl downloads the best Spotify match.
Batch files
List one link or ID per line in a text file. Lines that start with # are ignored.
Tags and cover art
Every file gets title, artist, album, year and front cover as ID3v2.4 tags, so your player shows them.
YouTube Music matching
Each track is looked up on YouTube Music first, and the result must agree with Spotify on title, artist, album and length. If nothing matches well, plain YouTube is used, with a length check, and the log says so. That filters out most wrong uploads. It can also skip real matches, such as live versions.
Parallel downloads
Three tracks download at once by default. Change it in Settings, with settings --parallel, or for one run with -j. The limit is 8.
Live details and cover art
Progress bars, speed, MB done, ETA, and the source and MP3 bitrate, sample rate and channels. The cover is also drawn as ASCII art in the terminal.
Menu or command line
Run it with no arguments for a full-screen menu, or use subcommands in scripts.
ISRC finder
Look up the ISRC code of a song, or list the codes of a whole playlist and save them as CSV or JSON. It only talks to Spotify, so it needs no yt-dlp or ffmpeg.
One exe
Written in Rust. No Node.js, Python or installer. It calls yt-dlp and ffmpeg, which you install once.

Get started

Five steps. You set up the Spotify side once, then it stays set up.

  1. Install yt-dlp and ffmpeg

    spotify-dl uses them to find and convert audio. You can also put yt-dlp.exe and ffmpeg.exe in the same folder as spotify-dl.exe.

    winget install yt-dlp.yt-dlp
winget install Gyan.FFmpeg

  2. Download spotify-dl

    Get spotify-dl-windows-x64.zip from the latest release and unzip it. It contains spotify-dl.exe and .env.example.

  3. Create a Spotify app

    Open the Spotify developer dashboard and create an app. In its settings, add this Redirect URI:

    http://127.0.0.1:5000/callback

    Use 127.0.0.1, not localhost. Spotify rejects the second one.

  4. Add your credentials

    Start spotify-dl, open Settings, and enter the client ID and client secret from your Spotify app. They are saved for next time.

    Prefer a file? Copy .env.example to .env next to the exe instead:

    SPOTIFY_CLIENT_ID=your_client_id
SPOTIFY_CLIENT_SECRET=your_client_secret

  5. Run it

    Double-click spotify-dl.exe, or run spotify-dl in a terminal.

Commands

Every menu action also works as a command, so you can script it.

spotify-dl commands
CommandWhat it does
spotify-dlOpen the terminal menu.
spotify-dl song <link|uri|id>Download one track.
spotify-dl album <link|uri|id>Download an album.
spotify-dl playlist <link|uri|id>Download a playlist you own or collaborate on.
spotify-dl query "Artist - Title"Search Spotify and download the best match.
spotify-dl file list.txtDownload every track listed in a text file.
spotify-dl isrc <link|uri|id|name>Show the ISRC code of a song, or list a playlist's codes.
spotify-dl isrc <...> --csv [file] --json [file]Also save the result as CSV or JSON.
spotify-dl loginLog in to Spotify again.
spotify-dl settings [--set <folder>]Show or change the download folder.
spotify-dl settings --client-id <id> --client-secret <secret>Save your Spotify credentials.
spotify-dl settings --parallel <n>Save how many tracks download at once (1 to 8).
spotify-dl -p <folder> <command>Use another folder for this run only.
spotify-dl -j <n> <command>Download n tracks at once for this run only.

<link|uri|id> can be an open.spotify.com link, a URI such as spotify:track:4uLU6hMCjMI75M1A2tKUQC, or the 22-character ID.

Settings

Change these in the app's Settings screen, or put the credentials in .env.

spotify-dl settings
SettingWhere to set itNotes
Client IDSettings, or SPOTIFY_CLIENT_ID in .envRequired.
Client secretSettings, or SPOTIFY_CLIENT_SECRET in .envRequired.
Redirect URISPOTIFY_REDIRECT_URI in .envOptional. Defaults to http://127.0.0.1:5000/callback. Must match your Spotify app.
Download folderSettings, or settings --setPress Tab in Settings to complete folder names. Defaults to a spotify-dl folder inside your Music folder. Albums and playlists are saved in subfolders of it.
Parallel downloadsSettings, or settings --parallelTracks downloaded at the same time, 1 to 8. Defaults to 3.

Credentials saved in Settings are stored as plain text in %APPDATA%\spotify-dl\config.json. A value in .env or an environment variable overrides the saved one.

Playlists need a Spotify login. The first playlist download opens your browser, and the login is saved in %APPDATA%\spotify-dl, not next to the exe. Spotify only lists tracks for playlists you own or collaborate on. Keep .env private and never commit it.
